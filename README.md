# 3D 粒子照片圣诞树网页

深邃夜空下，一棵由 **15,000 颗发光粒子** 螺旋汇聚而成的 3D 圣诞树缓缓旋转，挂满拍立得记忆照片与圣诞灯火；轻点树身或按钮即可瞬间散开为漫天星尘云，再点又重新聚合成树。纯前端**单文件零外链依赖版**（Three.js r128 已完整内联），无需后端服务器与外部 CDN，国内网络双击或部署至静态托管即可直接打开和体验。

---

## 如何打开

### 方式一：直接双击打开（最简单）
直接双击当前目录下的 `index.html`，使用现代浏览器（Chrome / Edge / Safari / Firefox）打开即可浏览。  
> `index.html` 已内联非 module 的 Three.js r128 UMD 核心库，零外链依赖，对 `file://` 本地协议与完全断网环境均完全兼容。

### 方式二：通过本地 HTTP 服务打开（推荐，体验完整手势模式）
在当前目录打开终端并运行：

```bash
python3 -m http.server 8080
```

随后在浏览器中访问 `http://localhost:8080`（或 `http://127.0.0.1:8080`）。  
> 如需体验「手势模式」调用摄像头，浏览器安全策略要求页面运行在 `http://localhost` 或 `https://` 环境下，且需联网按需加载手势识别组件。

## 按钮与交互说明

### 页面直接交互
- **旋转视角**：鼠标左键按住拖拽（移动端单指滑动）可自由旋转观察角度；松手后圣诞树恢复缓慢自动旋转。
- **缩放远近**：鼠标滚轮（移动端双指捏合）可拉近或推远镜头（距离限制在 `18 ~ 58` 之间）。
- **散开 / 聚合切换**：单击树身区域（非照片位置）或双击画布，即可切换圣诞树「聚合成树（FORMED）↔ 散开成星尘（CHAOS）」状态。
- **放大查看照片**：点击挂在树上或悬浮在星尘中的任意一张拍立得照片卡，可居中弹出高清放大预览；点击空白处、右上角 `×` 或按 `ESC` 键关闭。

### 底部玻璃拟态控制条与右上角按钮
- **散开成星尘 / 聚合成圣诞树**：一键触发双状态平滑形变（约 1.8 秒缓动过渡），照片卡随粒子同步飞散或归位。
- **上传照片（当前数量/12）**：打开本地文件选择器添加自己的照片，挂到圣诞树上成为拍立得卡片。
- **音乐（底部「音乐」/ 右上角「八音盒：关/开」）**：默认静音关闭；点击后通过浏览器 Web Audio API 现场合成分解八音盒版《We Wish You a Merry Christmas》循环播放，再点停止。
- **手势模式**：按需开启摄像头手势识别（不点击此按钮绝不申请摄像头或加载识别脚本）。开启后支持：**张开手掌 = 散开成星尘**、**握拳 = 聚合成圣诞树**、**手掌左右移动 = 控制旋转**。右下角会显示镜像小窗预览，可随时点击小窗 `×` 或按钮关闭并释放摄像头。
- **全屏**：切换浏览器全屏沉浸模式（部分受限环境或内置 WebView 会提示不支持）。
- **祝福语输入框 + 确认**：输入自定义圣诞祝福语后按回车或点击「确认」，顶部祝福语立即更新生效。

## 如何更换自己的照片

1. 点击底部控制条的 **「上传照片」** 按钮（支持一次多选 `JPG` / `PNG` / `WebP` 等常见图片格式）。
2. 系统会自动将照片居中裁切并套上奶白色拍立得相纸边框，生成新的 3D 照片卡挂到圣诞树上（页面**已内置 12 张照片（可自行替换/删除/增补）**，最多共可挂 **12 张**）。
3. 当照片总数达到 12 张上限后继续上传时，会优先按顺序替换最早的默认内置照片卡（若全部为用户新上传的照片，则按先进先出顺序替换最早上传的卡片）。

> **隐私声明**：所有照片均通过浏览器 `FileReader` 与 `CanvasTexture` **全程在本地浏览器内存中处理，绝不上传至任何服务器或云端**。

## 管理照片

点击树上或星尘中的任意一张拍立得卡片打开放大预览遮罩后，除原有的右上角 `×` 按钮、点击空白处及按 `ESC` 关闭方式外，还提供两个玻璃拟态管理按钮：

1. **替换这张**：打开本地单图文件选择器，选中 1 张本地图片后仅替换当前卡片的画面与底部配文，卡片所在位置、当前展开状态（`FORMED` / `CHAOS`）及底部照片计数均保持不变，放大预览图同步刷新为新图；若取消选图，界面保持原样且无任何报错。
2. **删除这张**：将该照片卡从 3D 场景与数据列表中彻底移除并释放对应纹理与几何体资源，底部计数即时更新（如 `12/12 → 11/12`），剩余照片按螺旋/星尘布局自动重排。无论在 **聚合（FORMED）** 还是 **散开（CHAOS）** 状态下均可安全删除，默认内置照片卡与用户上传卡逻辑一致；支持一直删至 `0/12` 张（0 张时圣诞树与全部功能照常运行），删出空位后可继续通过「上传照片」补充新照片。

## 如何修改祝福语

- **方式一（页面内修改）**：在底部控制条的输入框中输入祝福语（最多 60 字），按下回车键或点击 **「确认」** 按钮，顶部标题 `Merry Christmas` 下方的祝福语将即时更新，并同步写入地址栏 `?msg=` 参数。
- **方式二（URL 参数预设）**：在链接末尾加上 `?msg=你的祝福语` 即可预设初始祝福语（例如：`index.html?msg=这个冬天，愿你万事胜意`）。

## 已知限制

1. **纯本地内存状态**：为遵守纯静态无后端原则，本地上传/替换/删除的照片与自定义输入仅保存在当前浏览器页面内存中，刷新页面后会恢复为默认内置的 12 张拍立得照片（祝福语可通过 `?msg=` 参数在链接中保留）。
2. **手势模式依赖安全上下文与按需联网组件**：受浏览器安全规范限制，摄像头权限通常仅在 `http://localhost` 或 `https://` 下可用，`file://` 双击打开时点击手势模式会弹出友好轻提示而无法启用摄像头；点击开启时按需懒加载 `@mediapipe/hands`（优先尝试国内 `npmmirror` 镜像，失败后自动回退 `jsdelivr`），不点击则绝不发出任何外部请求，加载失败或无摄像头时自动隔离降级，不影响其余任何功能。
3. **3D 渲染依赖 WebGL（Three.js 已内联，完全断网可用）**：本文件为单文件零外链依赖版，Three.js r128 已全文内联进 `index.html`，国内网络双击或断网环境下均可直接渲染运行；若浏览器未开启 WebGL 图形加速，页面会展示友好的毛玻璃提示文案而非白屏。

## 自检记录

于本地通过 `python3 -m http.server` 启动静态服务，并使用 Headless Chromium（开启 WebGL / SwiftShader）及 `file://` 直接打开进行了逐条自动化与截图实测，结果如下：

1. **场景（星空、飘雪、地面光晕）**：实测通过。深黑蓝夜空背景下渲染 **1,500 颗** 闪烁星点、**1,200 朵** 循环下落且带微风摆动的雪花粒子，树底有祖母绿与暖金色渐变微光倒影圆盘。
2. **粒子圣诞树与树顶星**：实测通过。`TREE_PARTICLE_COUNT = 15000`（在 12,000–16,000 区间），螺旋灯带 + 分层圆锥成型，配色以祖母绿打底并混入金/红/暖白闪烁灯饰，采用 Canvas 径向光点贴图与 `AdditiveBlending`；树顶配备 3D 挤出金色五角星与呼吸光晕精灵。
3. **双状态形变与轨道控制**：实测通过。页面默认 `FORMED` 并缓慢自动旋转；实测点击「散开成星尘」按钮与双击画布均在约 `1.8s` 内平滑完成 `FORMED ↔ CHAOS` 状态过渡；支持鼠标/触屏拖拽旋转及滚轮/双指缩放（半径限制 `18 ~ 58`）。
4. **拍立得照片卡与放大预览**：实测通过。内置 8 张各不相同的 Canvas 程序绘制圣诞插画拍立得（无外链、无 emoji、无真人图片），背面为墨绿金纹相纸且不透视粒子；`FORMED` 时螺旋挂于树表微摆，`CHAOS` 时分布于星尘球面并朝向镜头；点击可打开居中高清预览遮罩并关闭。
5. **本地上传换照片**：实测通过。单张上传测试从 `8/12` 增至 `9/12`，多张连续上传验证总数严格限制在 `12/12` 并自动替换早期默认卡，全程本地处理无网络上传请求。
6. **Web Audio 八音盒音乐**：实测通过。默认关闭；点击右上角或底部音乐按钮后成功合成播放八音盒版《We Wish You a Merry Christmas》，状态显示同步切换为「八音盒：开」，再次点击平滑停止。
7. **发光标题与可编辑祝福语**：实测通过。顶部金色发光 `Merry Christmas` 标题及祝福语正常渲染；实测 URL `?msg=` 参数预设生效，底部输入框提交后即时更新祝福语。
8. **隔离手势模式**：部分实测（逻辑与容错隔离通过，实机手势轨迹未触发）。验证未点击手势按钮前零摄像头请求、零控制台报错；在无摄像头无头环境下点击「手势模式」按钮时，安全捕获异常并弹出轻提示、保持 `gestureActive: false`，未抛出 `pageerror` 且页面其余功能正常。因验证环境无物理摄像头，张开/握拳/挥动识别分支仅在代码路径完成接入，未进行物理摄像头实拍追踪测试。
9. **极简玻璃拟态 UI 与移动端适配**：实测通过。底部居中控制条与右上角悬浮音乐/提示栏显示完整；在 `390×844` 移动端视口下实测 `scrollWidth === 390`，无水平溢出。
10. **性能与稳健**：实测通过。限制 `pixelRatio <= 2`；配置 `visibilitychange` 后台暂停渲染、窗口 `resize` 自适应及 WebGL/Three.js 加载失败友好降级屏；全流程 `http://` 与 `file://` 打开均实现 **0 条 `console.error`** 与 **0 条 `pageerror`**。
